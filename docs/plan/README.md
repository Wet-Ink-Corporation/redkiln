# The live plan

`references/` is the planning handover, frozen on 2026-10-19. Its migration plan (`references/docs/migration-plan.md`) is still the plan: the move order, the gates, the eight steps of a move and the principles stand as signed off. This folder holds what has happened since: where each gate stands, which parts of the frozen text later decisions replaced, and the runbook for the next move. Where this folder and `references/` disagree, this folder is newer; where this folder and `AGENTS.md`, `docs/decisions.md` or `spec/` disagree, those win, because they are the checked rules.
