# Move 2 runbook: Bench

anneal moves from `Wet-Ink-Corporation/anneal` into this repository as Bench: the `rk-bench` plugin, its cockpit mod and its crates. It is the second move, and the one where Core and the SPEC freeze at 1.0, because anneal's ledger is Core's second real user. Its code also seeds two kits (`redkiln-guard`, `redkiln-github`) and a Core crate (`redkiln-calibrate`). `rk-bench` is not released at this move: it ships 0.1.0 once it runs on the catalog Loop brings at Move 4 (migration call D, Bench call E).

anneal finished its move preparation on 2026-11-09, and Ryan froze it until this move: only security fixes land there. anneal's own side of the move is its import manifest, `docs/redkiln-move.md` in anneal, which this runbook is written from, the way the Move 1 runbook was written from Weigh-In. It does not re-plan: the end state is `references/docs/bench.md`, the formats are `spec/`, the rules are `AGENTS.md`, and the template is [move-1-weigh-in.md](move-1-weigh-in.md). Where this file names a choice those leave open, it says whether it is a two-way default or a call for Ryan.

## What is different about this move

- **Nothing is released.** `rk-bench` waits for the catalog (migration call D), so this move ends with the code here, green and conforming, and anneal archived; Ryan's anneal 0.0.5 install keeps working from the archived repository's `marketplace` branch until `rk-bench` 0.1.0 replaces it. No release workflow, release repository entry or human surface check is needed until then.
- **Core and the SPEC freeze.** The SPEC's "Not in this draft" parts that arrive with Move 2 (the end-of-turn grammar, the hook conventions, calibration records) are written, Bench's ledger conforms, and SPEC 1.0.0 and Core 1.0 are cut. Every OW item is then expensive to change.
- **The binary is large.** About 137.8k lines of Rust in two crates, tests included (116.5k under `anneal-cli/src`), against about 24.5k for weigh-in 1.2.0 counted the same way. Most of the move's work is cutting it into kits and tools once it is here, each cut once, in the monorepo.
- **It brings guards.** Four `PreToolUse` hooks fail closed (`guard`, `merge-gate`, `preconditions`, `brief`, each `--fail-closed` with `onFailure: block`), so CLI-11's Windows no-build hole (M1-E) must be closed before `plugins/bench/` is installed anywhere.
