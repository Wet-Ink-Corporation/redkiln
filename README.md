# redkiln

The Redkiln suite's monorepo: Claude Code plugins (`rk-*`) for Rust craft, specs and builds, decisions, review, unattended runs, knowledge and backlog, over shared Core, kit and contract crates.

It is in phase 0: the workspace, its layer check, CI, the shared plugin launcher and the suite label manifest are here, and the products move in one at a time behind the gates in [the migration plan](references/docs/migration-plan.md). Start with [AGENTS.md](AGENTS.md) for how the repository is laid out and checked, and [references/](references/README.md) for the plan behind it.
